# Python Programming Course
In this repository, we have designed the Python Programming course for Zindua School's Software Engineering and Data Science programs. 

- **Course Description:** A 5-week course that takes learners from writing their first line of Python to building complete, well-structured programs. Learners build progressively — core syntax and control flow, then Python's data types and APIs, then regular expressions, web scraping and web services, then object-oriented programming and databases — before applying everything in a capstone project.

- **Course Objective:** Equip learners to write clean, modular and tested Python programs that work with files, data structures, web services and databases, forming the foundation for the software and data modules that follow.

- **Skills to be learned:** Python syntax, control flow, functions, strings & files, lists, tuples, dictionaries & sets, APIs, regular expressions, web scraping (requests, BeautifulSoup), object-oriented programming, SQL & NoSQL databases, modules & packages, unit testing

## Curriculum Breakdown
### Week 1: Python Basics
> **Objective:** Write and run your first programs: learners will be able to set up a Python environment, use variables, expressions and statements correctly, control program flow with conditionals and loops, and break problems into reusable functions.
1. Introduction to Python
2. Variables, Expressions, Statements
3. Conditionals & Functions
4. Loops & Iterations
5. Weekly Practice Project
### Week 2: Python Data Types
> **Objective:** Work fluently with Python's core data structures: learners will be able to manipulate strings and read and write files, choose between lists, tuples, dictionaries and sets for a given task, and retrieve and parse data from a public API.
1. Strings & Files
3. Lists & Tuples
4. Dictionaries & Sets
5. APIs
6. Weekly Practice Projects
### Week 3: Python Web Services
> **Objective:** Collect data from the web: learners will be able to extract patterns from text with regular expressions, scrape structured data from web pages, and consume web services that return JSON and XML.
1. Regular Expressions
2. Regular Expressions
3. Web Scraping
4. Using Web Services
5. Weekly Practice Project
### Week 4: Advanced Python
> **Objective:** Structure programs for growth: learners will be able to model problems with classes, inheritance and encapsulation, persist data in SQL and NoSQL databases, and organise code into modules and packages covered by unit tests.
1. Object-Oriented Programming
2. Advanced Object-Oriented Programming
3. Working with SQL & NoSQL Databases
4. Best Practices(Modularisation & Unit Testing)
5. Weekly Practice Project
### Week 5: Conclusion
> **Objective:** Apply the full course in a working project: learners will be able to plan, build and present a complete Python application that combines data structures, external services and object-oriented design.
1. **Capstone Projects:** Tic-Tac-Toe Game (GUI), Discord/Slackbot (APIs), Instagram Bot (Browser Automation), YouTube Downloader (APIs + GUI), Sudoku Solver (Backtracking + GUI)
2. **BONUS Resource 1:** More advanced Python i.e. Generators, Decorators, Closures, Expection Handling, List Comprehension, Map-Filter-Reduce
3. **BONUS Resource 2:** Build Graphical User Interfaces (GUIs) with Tkinter
4. **BONUS Resource 3:** Deploying Python serverless scripts on the cloud i.e. AWS Lambda, Azure Functions, Google Cloud Functions
5. **Further Resources:** Official Documentation, W3 School Python Notes, Project Euler Challenges, Recommended Python Books, Recommended Python Blogs
