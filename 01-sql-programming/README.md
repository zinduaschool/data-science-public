# General Data Analysis Course
Official curriculum for the General Data Analysis course in Zindua's Data Science Core Program.

- **Course Description:** A 4-week course that takes learners from their first database query to a complete, end-to-end analysis. Learners build progressively — querying relational data with SQL, then designing and optimising databases, then analysing data in Excel, and finally communicating findings through interactive Tableau dashboards — before bringing it all together in a capstone project.

- **Course Objective:** Equip learners to store, query, analyse and visualise structured data with SQL, Excel and Tableau, and to back every insight with a reproducible query, a clear analysis and a visual that states the takeaway.

- **Skills to be learned:** SQL (PostgreSQL/MySQL), relational database design, normalisation, indexing & query optimisation, transactions & ACID, views, stored procedures & triggers, Microsoft Excel (formulas, lookups, pivot tables, charts), Tableau (data connections, calculated fields, dashboards), data storytelling


### Curriculum Overview  

This course equips learners with essential tools for data analysis in **SQL, Excel, and Tableau** progressing from database fundamentals to advanced querying, database design, optimization, and interactive dashboard development.  

By the end of the course, learners will be able to:ls

- Design and query relational databases efficiently  
- Apply advanced SQL techniques for analytical workflows  
- Optimize database performance  
- Perform structured data analysis in Excel  
- Build interactive dashboards in Tableau  
- Deliver a complete, end-to-end data analysis project  

#  Curriculum Breakdown  

## Week 1: Databases & SQL
> **Objective:** Query relational data with confidence: learners will be able to explain how relational databases organise data, write SQL queries that filter, sort, join and aggregate data, and use subqueries, CTEs and window functions to answer multi-step analytical questions.

### 1.1 Introduction to Databases
- Introduction to Databases  
- Database Terminology  
- Installation of MySQL Workbench  

### 1.2 Introduction to SQL
- Introduction to SQL  
- Creating Tables  
- Inserting Data  

### 1.3 Basic SQL Queries
- `SELECT` and `WHERE`  
- `ORDER BY` and `LIMIT`  
- `UPDATE` and `DELETE`  
- Aggregate Functions  

### 1.4 Intermediate SQL Queries
- `GROUP BY` and `HAVING`  
- `CASE WHEN`  
- `JOIN` operations  
- Combined Queries  

### 1.5 Advanced SQL Queries
- Nested Queries  
- Common Table Expressions (CTEs) – `WITH` Clause  
- Window Functions  

**Project:** [SQL Week One Project](https://classroom.github.com/a/2b5f98g5)  

## Week 2: Database Design & Optimization
> **Objective:** Design databases that stay correct and fast as they grow: learners will be able to model a business domain as a normalised schema, automate logic with views, stored procedures and triggers, protect data integrity with transactions, and diagnose and fix slow queries with indexes and query plans.

### 2.1 Database Objects & Automation
- Views  
- Triggers  
- Stored Procedures  

### 2.2 Database Design (Schema Design)
- Database Design Principles  
- Entity Relationship (ER) Diagrams  
- Normalization  

### 2.3 Advanced Database Design
- Denormalization  
- Schema Trade-offs  

### 2.4 Transactions & ACID
- Transactions  
- Transaction Control Language (TCL)  
- Isolation Levels  

### 2.5 Performance & Optimization
- Indexing  
- Partitioning  
- Query Optimization  

**Project:** [SQL Week Two Project](https://classroom.github.com/a/cwhqTgHW)  

## Week 3: Microsoft Excel for Data Analysis
> **Objective:** Analyse data efficiently in a spreadsheet: learners will be able to clean and structure raw data in Excel, apply logical, lookup and aggregation functions, summarise data with pivot tables, and build charts and simple dashboards that answer a business question.

### 3.0 Excel Fundamentals
- Introduction to Excel  

### 3.1 Introduction to Excel
- Excel Basics and Interface  

### 3.2 Excel Intermediate
- Intermediate Excel Techniques  
- Formulas and Functions  
- Data Manipulation  

### 3.3 Advanced Excel
- Advanced Functions  
- Lookup Techniques (`VLOOKUP`, `INDEX-MATCH`)  
- Pivot Tables  
- Power Query  

### 3.4 Excel Data Visualization
- Charts and Graphs  
- Dashboard Design  
- Data Visualization Best Practices  

**Project:** [Recruitment Data Project](https://classroom.github.com/a/4g2LF15G)  

## Week 4: Tableau for Data Visualization
> **Objective:** Turn analysis into interactive visual stories: learners will be able to connect Tableau to multiple data sources and model their relationships, build calculated fields and core chart types, and assemble interactive dashboards that guide an audience to a clear conclusion.

### 4.1 Introduction to Tableau
- Introduction to Tableau  
- Installing Tableau  
- Tableau Public  

### 4.2 Connecting to Data
- Connecting to Data Sources  
- Tableau Join Types  
- Data Blending  
- Relationships  
- Data Types and Connections  

### 4.3 Data Visualization
- Tableau Visualization Basics  
- Interactive Dashboards  
- Storytelling with Data  

**Project:** Tableau Projects  

## Final Capstone Project
> **Objective:** Deliver an end-to-end analysis: learners will be able to design and populate a database for a real-world problem, analyse it with SQL and Excel, and present their findings in a Tableau dashboard backed by a clear data story.

Learners will design and present a complete data analysis pipeline, including:

- Database design and structured querying in SQL  
- Data extraction and transformation  
- Data cleaning and exploratory analysis in Excel  
- Interactive visualization and storytelling in Tableau  

**Deliverable:** A professional presentation showcasing actionable data-driven insights
