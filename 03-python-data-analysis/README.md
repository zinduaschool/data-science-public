# Python Data Analysis Course

Official curriculum for the Python Data Analysis module in Zindua's Data Analytics/Data Science core programs.

## Curriculum Breakdown

### Week 1: Foundations of NumPy

- **Introduction to the NumPy Array:** Array attributes, indexing arrays, slicing arrays, reshaping arrays, and joining arrays.
- **Computations on Arrays:** Universal functions, broadcasting, and aggregations.
- **Manipulating Arrays:** Comparisons, Boolean masks, fancy indexing, and structured data.

### Week 2: Foundations of Pandas

- **Pandas Foundations:** Data structures in Pandas, data indexing, and selection.
- **Pandas Data Manipulation:** Universal functions in Pandas, handling missingness, and hierarchical indexing.
- **Pandas Data Analysis:** Combining datasets, grouping, and aggregation.
- **Advanced Pandas Analysis:** Time-series analysis, working with strings, and high-performance Pandas.

### Week 3: Data Visualization

- **Matplotlib Foundations:** Visualization types with Matplotlib.
- **Customizing Plots:** Legends, color bars, ticks, stylesheets, and text annotations.
- **Advanced Visualizations:** 3D plots and visualizations with Seaborn.

### Week 4: Statistics and Probability

- **Statistics Fundamentals:** Introduction to statistics, descriptive statistics, and inferential statistics.
- **Distributions:** Introduction to probability distributions, discrete and continuous distributions, uniform and Poisson distributions, normal distribution, and the empirical rule.
- **Probability Theory:** Probability and likelihood, marginal and joint probability, conditional probability, independence, Bayes' theorem, and the law of total probability.
- **Hypothesis Testing:** Formulating hypotheses, choosing test directions, Type I and Type II errors, p-values, statistical and practical significance, test statistics, sampling distributions, A/B testing, comparing groups with statistical tests, and statistical power.
