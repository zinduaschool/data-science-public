# Python Data Analysis Course

Official curriculum for the Python Data Analysis module in Zindua's Data Analytics/Data Science core programs.

- **Course Description:** A 5-week course that takes learners from raw arrays to statistically grounded insight. Learners build progressively — numerical computing with NumPy, then data wrangling and analysis with Pandas, then visualisation with Matplotlib and Seaborn, then the statistics and probability needed to draw sound conclusions — before completing a capstone analysis.

- **Course Objective:** Equip learners to load, clean, transform, visualise and statistically analyse real-world datasets in Python, and to support every conclusion with evidence rather than intuition.

- **Skills to be learned:** NumPy, Pandas, Matplotlib, Seaborn, data cleaning, missing-data handling, grouping & aggregation, time-series analysis, descriptive & inferential statistics, probability distributions, hypothesis testing, A/B testing


## Curriculum Breakdown

### Week 1: Foundations of NumPy
> **Objective:** Compute efficiently on numerical data: learners will be able to create, index, slice and reshape NumPy arrays, apply vectorised universal functions, broadcasting and aggregations, and filter data with Boolean masks and fancy indexing.

- **Introduction to the NumPy Array:** Array attributes, indexing arrays, slicing arrays, reshaping arrays, and joining arrays.
- **Computations on Arrays:** Universal functions, broadcasting, and aggregations.
- **Manipulating Arrays:** Comparisons, Boolean masks, fancy indexing, and structured data.

### Week 2: Foundations of Pandas
> **Objective:** Wrangle tabular data: learners will be able to load data into Series and DataFrames, select and transform it, handle missing values and hierarchical indexes, combine and group datasets, and analyse time series and text columns.

- **Pandas Foundations:** Data structures in Pandas, data indexing, and selection.
- **Pandas Data Manipulation:** Universal functions in Pandas, handling missingness, and hierarchical indexing.
- **Pandas Data Analysis:** Combining datasets, grouping, and aggregation.
- **Advanced Pandas Analysis:** Time-series analysis, working with strings, and high-performance Pandas.

### Week 3: Data Visualization
> **Objective:** Communicate patterns visually: learners will be able to choose the right chart type for a question, build and customise plots with Matplotlib, and produce clear statistical visualisations with Seaborn.

- **Matplotlib Foundations:** Visualization types with Matplotlib.
- **Customizing Plots:** Legends, color bars, ticks, stylesheets, and text annotations.
- **Advanced Visualizations:** 3D plots and visualizations with Seaborn.

### Week 4: Statistics and Probability
> **Objective:** Draw sound conclusions from data: learners will be able to summarise data with descriptive statistics, reason with probability and common distributions, and design and interpret hypothesis tests, including A/B tests, with attention to errors, p-values and power.

- **Statistics Fundamentals:** Introduction to statistics, descriptive statistics, and inferential statistics.
- **Distributions:** Introduction to probability distributions, discrete and continuous distributions, uniform and Poisson distributions, normal distribution, and the empirical rule.
- **Probability Theory:** Probability and likelihood, marginal and joint probability, conditional probability, independence, Bayes' theorem, and the law of total probability.
- **Hypothesis Testing:** Formulating hypotheses, choosing test directions, Type I and Type II errors, p-values, statistical and practical significance, test statistics, sampling distributions, A/B testing, comparing groups with statistical tests, and statistical power.

### Week 5: Conclusions
> **Objective:** Deliver a complete analysis: learners will be able to take a real-world dataset from cleaning through visualisation and statistical testing to a clearly communicated set of findings.
