# Bonus: Data Storytelling with Excel & Power BI
Official Curriculum for Data Storytelling with Ms.Excel & Power BI in Zindua's 30 Day Challenge Series.

- **Course Description:** A 4-week bonus course that takes learners from spreadsheet basics to compelling data stories in Power BI. Learners build progressively — organising and analysing data in Excel, then advanced lookups, pivot tables and dashboards, then loading and modelling data in Power BI — before telling a complete data story in a capstone report.

- **Course Objective:** Equip learners to clean, analyse and visualise data in Excel and Power BI, and to turn dashboards into data stories that lead an audience to a clear decision.

- **Skills to be learned:** Microsoft Excel (functions, lookups, pivot tables, charts, dashboards), Power BI (Power Query, data modelling, DAX, visuals, reports), data storytelling

## Curriculum Breakdown

---

### Week 1: Basic to Intermediate Excel
> **Objective:** Organise and analyse data in Excel: learners will be able to navigate workbooks, sort, filter and format data, and use formulas, cell references and conditional, aggregation and text functions to answer questions.
- **Lesson 1:** Getting Started with Excel: Navigating Excel, navigating the excel interface,workbook versus spreadsheet,cells, ranges,inserting data,saving your first spreadsheet.
- **Lesson 2:** Basic Data Management and Organisation:Filtering, sorting, grouping and conditional formating.
- **Lesson 3:** Introduction to Excel Functions and Formulas: Functions versus formulas,cell referencing types, basic statistical functions, conditional and logical operators, conditional functions.
- **Lesson 4:** Intermediate functions: Conditional aggregation functions, text functions
- **Projects:** Summary of the weekly project(s)
### Week 2: Advanced Excel
> **Objective:** Summarise and present data in Excel: learners will be able to combine data with lookup functions, analyse it with pivot tables, troubleshoot common errors, and build charts and dashboards.
- **Lesson 1:** Look-up functions: V LOOK up, index and match functions
- **Lesson 2:** Excel Pivot tables: Inserting pivot tables, field in your pivot table, the analyze and design tab, sorting & filtering pivot tables,using recommended pivot tables, advanced analysis with pivot tables.
- **Lesson 3:** Trouble shooting common errors in Excel and how to fix them: 
- **Lesson 4:** Data Visualization with Excel: Chart types and how to use them, Excel dashboards
- **Projects:** Summary of the weekly project(s)
### Week 3: Introduction to Power BI
> **Objective:** Prepare data for analysis in Power BI: learners will be able to connect to multiple data sources, clean and transform data with Power Query, and build a data model with relationships and DAX measures.
- **Lesson 1:** Getting started with Power BI: What is Power BI, Why learn Power BI, Installation and Tour of the Power BI Interface
- **Lesson 2:** Connecting to Data Title: Connecting to different data sources in Power BI- csv, excel, bigquery, folders, pdfs etc...
- **Lesson 3:** Data Transformations: Introduction to Power Query Editor,Cleaning data and transforming data with Power Query
- **Lesson 4:** Advanced Data Transformatios: Joining tables & relationships, DAX, Query groups, Data Modelling
- **Projects:** Summary of the weekly project(s)
### Week 4: Data Storytelling with Power BI
> **Objective:** Tell a story with data: learners will be able to design and format effective visuals, assemble interactive dashboards and reports, and structure a data story that moves from context to insight to recommendation.
- **Lesson 1:** Data Visualization & Formating: Creating your first chart, chart types, formating charts, Top N charts
- **Lesson 2** Dashboards & Reports with Power BI: Compiling your first dashboard, page view and size, visual interactions 
- **Lesson 3:** Data Storytelling with Power BI: Difference between a report and a data story, anatomy of a good data story
- **Lesson 4:** Capstone Project
